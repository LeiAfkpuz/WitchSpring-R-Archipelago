# WitchSpring-R-Archipelago
Repository for my attempt at the WitchSpring R Archipelago randomizer! 


You must launch the WitchSpring R Client from Archipelago BEFORE launching the game
1. Install BepInEx IL2CPP into the WitchSpring R game folder
   Tested with BepInEx 6.0.0-be.755
2. Launch the game once for the folders to be created
3. Place the WitchSpringRArchipelago.dll into the new BepInEx/plugins folder
4. Launch the WitchSpring R Client from Archipelago
5. Connect to your slot in the client
6. Launch WitchSpring R game
